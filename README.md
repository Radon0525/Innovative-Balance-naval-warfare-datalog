# Innovative Balance Naval Warfare Datalog

HOI4の大型砲と航空対艦攻撃の命中・成功数、耐久・指揮統制ダメージを記録するWindows用ツールです。通常版のみを配布します。

## 初回の準備

1. Windows用の64-bit Python 3.12を、Python Launcher・Tcl/Tkを含めてインストールします。
2. GitHubの「Code → Download ZIP」で取得し、ZIPを展開します。
3. `setup.cmd`を開きます。初回は依存パッケージの取得にインターネット接続が必要です。
4. HOI4を起動して`起動.cmd`を開き、「収集開始」を押します。
5. 試合が終わったら「停止・保存」を押します。

陸戦集計ソフトのインストールは不要です。Python不要の実行ファイル版ではなく、ソース配布版です。

## 集計と結果

- 大型砲の射撃判定数・命中・不命中・命中率。
- 航空攻撃の参加機数・成功機数・成功割合。
- 攻撃元と被攻撃艦ごとの耐久・指揮統制ダメージ。
- 対戦国を自動判別し、A国→B国とB国→A国を左右に表示。
- 海戦参加の艦載機、空母発進の外部Naval Strike、基地航空の外部対艦攻撃などを経路別に集計。
- 各国最大5件の艦載機攻撃を抽選し、計算過程をTkinterで表示。

計算例は行をダブルクリックして開きます。航空隊別の火力集約、妨害による火力係数、対空軽減、成功機数、クリティカル、計算ダメージと実際の減少を表示します。未取得値を推測で補いません。

通常版では赤青比較、妨害を与えた航空隊の追跡、地域全体の護衛内訳、任務登録経路の追跡は行いません。これらは開発用の詳細解析機能です。通常版の実ゲームでの速度改善率は未測定です。

## 試合ごとの保存と比較

「収集開始」から「停止・保存」までが1セットです。全履歴を合算せず、開いている記録だけを集計します。ゲーム内で複数の戦闘が発生した場合は、そのセットに含まれます。

開始前に試合名を付けられます。「過去の記録・比較」から過去の試合を開き、名前・設計メモを保存し、2～6件の試合を比較できます。設計変更前に停止して、次の条件は新しく収集してください。

結果は`recordings/`に保存します。SQLiteによる差分保存とページ表示を使用します。移動・バックアップには、停止後の記録フォルダー全体をコピーしてください。CSVの累積値は行を合計せず、最新値か前後の差を使います。

## 対応環境と計測範囲

- Windows 64-bit、正規にインストールされたHOI4が必要です。
- 対応版は`profiles.json`の1.19.2／1.19.3のSHA-256と一致する実行ファイルです。版名が同じでも未登録のファイルには接続しません。
- ゲームの命令位置を確認してからFridaで観測します。ゲームの能力値・乱数・命中結果は変更しません。
- 大型砲の判定数は砲弾数ではありません。航空の成功機数も各機の独立した命中抽選ではありません。
- ダメージ集計は直接適用処理で実際に減った量です。過剰ダメージ、火災等の後続損害は含めません。
- 艦別集計は最大20,000組、個別判定例は先頭2,000件。艦載機計算例は方向別最大5件、方向数は最大128組です。上限・取得失敗は表示します。
- 全ゲーム処理や全港湾攻撃経路の記録ではありません。長時間・マルチプレイでの負荷や同期は未検証です。

ゲーム本体、個人の観測記録、Python環境、Dev版は同梱しません。同じゲームへ複数の収集ソフトを同時接続しないでください。

## 動作確認

セットアップ後、以下でテストを実行できます。

```bat
.venv\Scripts\python.exe -m unittest test_native test_app test_details test_damage test_storage test_history test_ui test_air_trace
```

公開準備時点で38テストが成功しています。ネイティブ観測のテストは一時的なPython子プロセスを使い、HOI4には接続しません。依存ソフトウェアにはそれぞれのライセンスが適用されます。
